# Orchestra — live floor

A simulated, ink-drawn model of Orchestra, a robot-run art installation for Bangalore. One open floor: visitors walk a U around a central robot orchestra (conductor, 12 dancing SO-101s, xylophone, drums, DJ desk, a floating projection screen) while the stations around it print, assemble, paint, brew, fold and play chess. Everything runs on one 64-second score; during the Tutti the whole room stops working and dances. Press \"sound off\" to hear it.

Open `index.html` in a browser (it is a single self-contained file).
