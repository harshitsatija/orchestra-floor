# Orchestra — live floor

A simulated, ink-drawn model of Orchestra, a robot-run art installation for Bangalore: print farm, drone runners, charm assembly line, robot DJ, painting counter, chess, T-shirt folding, Sisyphus and Rocky.

Open `index.html` in a browser (it is a single self-contained file).

Credits: SO-101 arm geometry by TheRobotStudio (Apache-2.0). People and Rocky by Quaternius / Tomás Laulhé (CC0). PA speaker by iPoly3D (CC0). Dress form by reyshapes (CC0). Rendering: three.js.
